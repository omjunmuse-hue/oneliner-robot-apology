A two-line robot confession, at most 400 characters: one sentence owning a specific mistake, one naming the lesson and the fix that follows from it. The program writes both lines to /output/entry.txt and an AI judge picks the apology that owns the more specific mistake.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
